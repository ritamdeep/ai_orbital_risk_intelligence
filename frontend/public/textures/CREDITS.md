# Earth Imagery & Texture Credits

All Earth surface, night-lights, topography, ocean specular, and cloud textures in this directory are derived from **public-domain NASA imagery** (repackaged for Three.js WebGL examples, self-hosted locally for offline operation):

- **Day Color Maps (`earth_day_2048.jpg`, `earth_day_4096.jpg`):** NASA Visible Earth — *Blue Marble: Next Generation* (Reto Stöckli / NASA Earth Observatory). Public Domain.
- **Night Lights Map (`earth_night_2048.jpg`):** NASA Earth Observatory — *Black Marble* (Suomi NPP VIIRS). Public Domain.
- **Topography Normal Map (`earth_normal_2048.jpg`):** Derived from NASA SRTM / GTOPO30 global elevation datasets. Public Domain.
- **Ocean Specular Mask (`earth_specular_2048.jpg`):** Derived from NASA Blue Marble land/water mask. Public Domain.
- **Cloud Layer (`earth_clouds_1024.png`):** Derived from NASA Visible Earth global cloud mosaic. Public Domain.

Reference package: [three.js planet texture examples](https://github.com/mrdoob/three.js/tree/dev/examples/textures/planets) (MIT / NASA Public Domain imagery).
